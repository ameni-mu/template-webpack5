## 使用コマンド

### ローカルサーバーを起動

```bash
npm run start
```

開発環境用のローカルサーバーを起動します。  
webpack-dev-server が起動し、ファイルの変更を監視します。

---

### 開発用ビルド

```bash
npm run build:dev
```

development モードでビルドします。  
ファイルを監視し、変更があるたびに自動で再ビルドします。

---

### 開発用ビルド

```bash
npm run build:dev
```

### 本番用ビルド

```bash
npm run build:prod
```

production モードでビルドします。  
本番公開用のファイルを生成します。

---

### 画像圧縮

```bash
npm run imgmin
```

画像圧縮処理を実行します。
